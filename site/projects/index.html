Projects

Things I've built, shipped, or started and occasionally finished.

  • asknum-eval

    Evals for ask-a-question, get-a-number systems.

    A natural-language question goes in, a number from a governed data source comes out, and this repo checks the number. Two tiers over one golden eval set: a tool tier that grades the query engine, and an agent tier that grades the full pipeline, including refusals, caveats, and relative dates.

    Open source github

  • Corylus

    The control layer for an automated agentic work pipeline.

    Agents pick up tickets and ship work on a schedule, a judge agent reviews each attempt with a verdict and confidence score, and one screen puts the queue in front of you to approve, send back, or discard.

    Open source github

  • cleo-parchment

    A warm, earthy terminal color scheme in light and dark variants.

    Designed for long sessions: parchment base, ink foreground, green and gold accents. Ships for common terminals and CLI tools, and this site uses the same palette.

    Open source github

  • Flightdeck

    A desktop dashboard for running several AI coding agents across several projects.

    Every agent session in one glanceable window, grouped by project, with attention flags for anything waiting on approval and a command palette to dispatch new work.

    Paused github
