  • asknum-eval

    github

    I built evals for systems that answer questions with numbers. For a month with no data, “revenue was $0” is a plausible wrong answer: missing data isn't zero revenue. Tests that only check whether SQL runs won't catch that distinction. This eval requires a null result and rejects zero. The tool tier compares query results with expected values; the agent tier checks the question-to-answer pipeline, including refusals, caveats, and relative dates. The demo has 29 passes out of 30 in the tool tier, with one intentional skip for an out-of-scope question that requires an agent to refuse. That is a query-engine result, not end-to-end agent accuracy.

  • Corylus

    github

    I built a review interface for agent work. A ticket queue opens into the original request, the agent's attempt, a judge agent's verdict and confidence estimate, and a diff when the attempt includes git pointers. I can inspect the changes and send an attempt back with a revision note instead of approving it. The judge's confidence is an estimate; the decision is still mine.
